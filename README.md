# ENTRENAMIENTO APP — v1 - README.

## Qué hace

* Permite crear un entrenamiento indicando fecha y añadir varios ejercicios con series, repeticiones y peso.
* Permite ver una lista de los entrenamientos registrados y seleccionar uno para consultar su detalle.
* La aplicación tiene **3 vistas**: **Historial**, **Nuevo entrenamiento** y **Detalle del entrenamiento**; se navega entre ellas mediante botones y al seleccionar un entrenamiento.
* Los datos se almacenan únicamente en **arrays de JavaScript en memoria**: al cerrar o recargar la página, todos los entrenamientos registrados se pierden.
* Está desarrollada con **HTML, CSS y JavaScript vanilla** y publicada en **GitHub Pages**.

## Fuera de la v1

* No hay base de datos ni almacenamiento permanente.
* No hay registro, inicio de sesión ni perfiles de usuario.
* No hay edición ni eliminación de entrenamientos una vez creados.
* No hay gráficos, estadísticas, progreso, marcas personales ni análisis de rendimiento.
* No hay backend, API, frameworks de frontend ni librerías externas.
* No hay sincronización entre dispositivos.
* No hay exportación ni importación de datos.
